Parte Tecnologías (Aca ponele mucho enfasis porque es el mayor problema):
Quiero crear una sección “Tech Stack” para mi portafolio web con una estética futurista tipo sistema solar. La sección debe estar hecha en React y tener animaciones suaves y profesionales.

OBJETIVO GENERAL:
Las tecnologías deben simular planetas orbitando alrededor de un núcleo central. En el centro debe haber un icono de programación estilo "</>" o algo minimalista relacionado al desarrollo.

ESTRUCTURA:
Debe haber 3 anillos (órbitas) alrededor del centro:

1. Primer anillo → Backend
Tecnologías:
- Node.js
- Express
- MySQL
- Sequelize

2. Segundo anillo → Frontend
Tecnologías:
- HTML
- CSS
- React
- Figma

3. Tercer anillo → Lenguajes
Tecnologías:
- C
- JavaScript
- C#
- Java
- Python

REQUISITOS VISUALES:
- Cada tecnología debe usar su icono oficial.
- Los iconos deben girar alrededor del centro simulando órbitas.
- IMPORTANTE: los iconos NO deben girar sobre sí mismos; deben mantenerse derechos mientras orbitan.
- Cada anillo debe tener una velocidad distinta:
  - Backend → más rápido
  - Frontend → medio
  - Lenguajes → más lento
- Los anillos deben verse como líneas finas y elegantes.
- Fondo oscuro/futurista con glow suave.
- Estética minimalista y moderna.
- Debe ser responsive.

INTERACCIONES:
Al pasar el mouse sobre una tecnología:
- Mostrar una tarjeta flotante (tooltip/card).
- La tarjeta debe incluir:
  - Nombre de la tecnología
  - Nivel/progreso
  - Proyecto donde fue usada
  - Botón o link al proyecto

Cada vez que pases el mouse sobre un proyecto, se tiene que iluminar la parte de atras y agrandar, osea que quede fachero.
Cuando se clickea sobre una card, se tiene que desplegar una tarjeta grande en medio de la pantalla, que va a mostrar el proyecto mas detallado.
El fondo de la pagina se tiene que desenfocar un poco.
La tarjeta contiene:
- Carrousel de imagenes del proyecto
